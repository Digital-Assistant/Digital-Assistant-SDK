# Documentation

This folder holds the SDK's permanent documentation: the rules for writing it, the architecture map and the decisions
of record. Start with the page that matches your question.

| Page | What it holds |
|---|---|
| [`STYLE_GUIDE.md`](STYLE_GUIDE.md) | Where each kind of page lives, and the writing, formatting and diagram rules |
| [`architecture/overview.md`](architecture/overview.md) | Components, entry points, data stores and one request flow |
| [`adr/README.md`](adr/README.md) | The index of architecture decision records |
| [`ADR_POLICY.md`](ADR_POLICY.md) | How to add, change or delete an ADR |
| [`branch-protection.md`](branch-protection.md) | The rulesets on `dev` and `main`, and how to re-export them |
| [`agentic-readiness-history.md`](agentic-readiness-history.md) | How the SDK went from the first audit to the close-out audit, with dates |
| [`agentic-readiness/README.md`](agentic-readiness/README.md) | The state of the agentic-readiness work |
| [`agentic-readiness-report/`](agentic-readiness-report/README.md) | The audit reports: a frozen record, never edited |

Pages at the repository root:

- [`README.md`](../README.md): what the SDK is and how to build it.
- [`USAGE.md`](../USAGE.md): how a host page loads and configures the SDK.
- [`RELEASE_PROCESS.md`](../RELEASE_PROCESS.md): branches, releases and repository setup.
- [`AGENTS.md`](../AGENTS.md): the rules for AI coding agents.
- [`CONTRIBUTING.md`](../CONTRIBUTING.md): how a change reaches `dev`.
- [`SECURITY.md`](../SECURITY.md): how to report a vulnerability.
